# 设定登记表（作者填写）

这份表是**设定的唯一来源**。你按自己能接受的方式填就行：可以只填关键几栏、可以只写一段话，
也可以直接口述让我录入。填完/说完之后，我按编号实现，代码与提交信息都会引用这些编号，
方便对照"哪条设定对应哪段代码"。

> 规则：开发方不替你设计设定。表里没写的东西我不会自己补，会先来问你。

编号约定：微生物 `M-##`、过去生物 `B-##`、时代/维度 `E-#`、关键物品 `I-##`、
机器与工作方块 `X-##`、失落魔法/科技 `S-##`、剧情步骤 `P-##`。
