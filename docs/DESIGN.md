# 深时 Deep Time — 设计蓝图

版本：v0.1 草案（可随讨论修改）
目标平台：Minecraft 26.2 / NeoForge 26.2.0.88 / Java 25

---

## 1. 一句话

你不是在打怪升级，而是在**做考古**：从一台显微镜和几片培养皿开始，一层层剥开这个世界的历史，
克隆出生物过去的形态，最后造出能回到各个维度过去的机器，弄清原版世界里那些"说不通的地方"到底发生过什么。

## 2. 进度主轴（七个时代）

| 阶段 | 玩家在做什么 | 关键解锁 |
|---|---|---|
| I 显微镜时代 | 用显微镜看方块的微观结构、给生物采样，认识"微生物" | 微观视界、采样工具、菌种图鉴 |
| II 培养与测序 | 培养皿扩增菌种，测序仪读取 DNA，得到生命谱系 | 谱系树 UI、古DNA 片段 |
| III 化石与遗迹 | 挖化石、清理、提取古DNA | 化石层结构、清洗台 |
| IV 克隆时代 | 拼接基因，克隆出"过去的形态" | 克隆舱、远古克隆体 |
| V 失落魔法 | 解读符文石板，学会已失传的法术 | 符文系统、附魔替代品 |
| VI 失落科技 | 复原以太/时间核心，造机器 | 能源系统、时间核心 |
| VII 纪元之门 | 建造时间机器，前往各维度的过去 | 4 个过去维度、真相碎片 |

## 3. 核心玩法循环

```
采样 → 观察/培养 → 测序(谱系数据) → 克隆祖先形态
   ↑                                        ↓
失落魔法/科技 ← 探索过去维度 ← 时间机器 ← 谱系数据达标
   ↓
反哺：更强的采样/克隆能力 + 真相碎片 → 下一个纪元
```

设计原则：

- **观察先于力量**：每个时代都先给"看"的工具，再给"用"的工具。
- **谜题对应原版疑点**：每个过去维度解开一个原版未解之谜（见第 12 节）。
- **过去 ≠ 回到原版坐标**：过去维度是独立维度，用"纪元坐标"映射到主世界坐标，避免改动原版世界。

## 6. 维度（"过去的世界"）

命名原则：给每个维度一个"当时还很正常"的名字，玩家进去后慢慢发现它后来变成了什么。

| 维度 ID | 中文名 | 当时的样子 | 对应谜题 | 产出 |
|---|---|---|---|---|
| `deeptime:primordial_ocean` | 原初汪洋 | 温暖、浅海、巨大珊瑚与菌藻，微生物最丰富 | 远古守卫者的来历 | 菌种、海洋神殿原型 |
| `deeptime:verdant_overworld` | 苍翠主世界 | 大水、无怪物、原型村民聚居 | 村民/刌民的分裂 | 村民祖先 DNA、古代聚落 |
| `deeptime:temperate_nether` | 温润地狱 | 湿地、真菌森林、有水 | 为什么地狱曾经有水 | 猪灵/疣猪祖先 DNA、以太矿 |
| `deeptime:verdant_end` | 苍翠末地 | 有水的浮空世界、鸣唱森林 | 末影人为什么怕水 | 末影人祖先 DNA、时间核心材料 |

（可选第 5 个，后期再加）`deeptime:microcosm` 微观维度：把显微镜"看进去"，做小型采集玩法。

每个维度的构成：生态系统 + 3~5 个结构 + 1 个谜题链 + 独有资源。

### 7.2 微生物

微生物不做成普通实体，而是**数据 + 渲染**：菌种由数据组件描述，在显微镜 UI 与地面菌落方块上呈现。
另有 2~3 种可交互的小型实体（菌团/孢子云），用于战斗与采集。

## 9. UI / 界面

1. **显微镜 UI**：对焦滑条 + 缩放 + 微生物网格，点击锁定菌种。
2. **测序 UI**：序列比对，越接近完整度越高。
3. **谱系树 UI**：树状图，显示已解锁物种与分支关系（村民↔刌民、末影人↔…）。
4. **克隆舱 UI**：DNA 匹配度、营养液、进度。
5. **图鉴 Codex UI**：条目 + 剧情文本 + 未解之谜。
6. **纪元选择 UI**：时间轴，显示已解锁纪元与坐标。
7. **HUD 叠加**：微观视界（着色器/叠加层）、时间稳定度。

## 10. 技术架构

### 10.1 包结构

```
com.deeptime
  DeepTime              入口（模组总线 + 游戏总线）
  DeepTimeClient        客户端入口（渲染器/界面/粒子注册）
  registry/             DTRegistries 及各内容注册表
  item/ block/ entity/ blockentity/ menu/ network/
  research/             谱系数据、图鉴、玩家进度
  worldgen/             维度、生物群系、结构、特征
  datagen/              数据生成提供器
  client/               渲染器、界面、模型、粒子
  compat/               可选联动（JEI 等）
```

### 10.2 关键实现策略

- **注册**：统一走 `DTRegistries`；世界生成注册在维度阶段加入。
- **数据生成**：方块/物品/语言/战利品/配方/标签，以及维度的 `dimension_type`、`dimension`、
  `noise_settings`、`biome`、`structure`、`feature` 等 JSON，全部用 datagen 产出并提交。
- **网络**：自定义 payload 同步显微镜观察、测序进度、克隆进度、纪元坐标（服务端权威）。
- **玩家/世界数据**：已发现条目与纪元解锁用 NeoForge 数据附件 + `SavedData`。
- **渲染**：实体用自定义模型（Blockbench 导出）；微生物用数据驱动的渲染层。
- **兼容**：不硬依赖任何第三方模组；JEI 作为可选。

### 10.3 26.2 版本注意点

- 官方名称空间、无混淆：`net.minecraft.resources.Identifier`（不是 `ResourceLocation`）。
- Java 25 工具链。
- 详细 API 用法以官方 26.2 源码/文档为准，写作时逐条核对。

## 11. 素材规格（由你制作）

| 类型 | 规格 | 备注 |
|---|---|---|
| 物品贴图 | 16×16 PNG（可 32×32，需全 mod 统一） | `assets/deeptime/textures/item/<name>.png` |
| 方块贴图 | 同上 | `assets/deeptime/textures/block/<name>.png` |
| 方块模型 | JSON（可手写或 Blockbench 导出） | `.bbmodel` 会被构建排除，不会进 jar |

| 音效 | OGG（可选） | `assets/deeptime/sounds/` |

## 12. 谜题链（对应原版疑点）

| 原版疑点 | 线索来源 | 揭示的真相（草案） |
|---|---|---|
| 末影人为什么怕水 | 苍翠末地的水池与末影人祖先 | 末影人原本生活在水边，是"水"救了它们一次，之后水成了禁忌/契约 |
| 为什么猪灵、疣猪到主世界会僵尸化 | 温润地狱的水道遗迹 | 它们不是"怕主世界"，而是被一次跨维度污染改写了生理 |
| 为什么地狱和末地显然都曾有很多水 | 两个维度的沉积层、干涸水道 | 一次由失落的科技/魔法引发的事件抽干了两个维度的水 |
| 末地为什么只剩虚空 | 苍翠末地的边缘观测站 | 水的消失导致世界锚点崩塌，剩下的部分被"切掉"了 |
| 监守者为什么是瞎的 | 远古监守者克隆体 | 它原本是"听"世界的生物，退化是被改造的结果 |
| 远古守卫者为什么是残缺的 | 沉没神殿原型 | 它们是被留下来看守某样东西的"残次品" |
