# 配方登记表

格式见 [RECIPE_SPEC.md](RECIPE_SPEC.md)。编号 `R-##`，按你给的顺序排。
配方内容由作者提供，开发方不自行设计。已实现的配方都写在
`src/main/java/com/beyondtime/datagen/BTRecipeProvider.java` 里（代码生成，同时产出配方书解锁进度）。

填的时候可以直接复制下面的模板，把类型、输出、格子改掉：

```
[R-01] 有序合成 3x3   输出: 物品名(编号) x数量
格子1  格子2  格子3
格子4  格子5  格子6
格子7  格子8  格子9
```
