### R-04 采集器（无序合成）

```
玻璃瓶 ×3
铁锭   ×2
木棍   ×1
```

设计理由：3 个玻璃瓶是作者确认过的部分；铁锭做取芯机构，木棍做推杆。
采集器只够采 3 个样本，所以配方要便宜，不能比样本本身还贵。

### R-05 基础生物分析仪（3×3 有序）

```
铁锭   玻璃   铁锭
铁锭   铜锭   铁锭
空     红石   空
```

设计理由：铁框架 + 玻璃观察窗 + 铜核心 + 红石电路。不用紫水晶——显微镜已经吃掉了
紫水晶，分析仪应该在看完前几个样本后就能做出来。

> 配方书解锁目前走原版 `unlockedBy`（拿到铁锭/铜锭就显示）。按微生物/组织节点解锁
> 的闸门是下一轮的事，接口在 `KnowledgeListeners`。
